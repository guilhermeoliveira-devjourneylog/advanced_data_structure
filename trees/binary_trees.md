## Tree Definition

A tree is a data structure that simulates a hierarchical relationship among elements. Unlike linear structures, such as arrays or linked lists trees, are nonlinear data structures that organize data, in a branching format, each element in a tree is called a node. With the top most node known as the root is connected to other nodes through edges, representing parent child relationships. 
The root node is the starting point of the tree and each node, can have zero or more child nodes, with no children are called Leaf nodes, a tree also cannot have cycles.
